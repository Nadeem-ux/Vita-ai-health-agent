# Vita-ai-health-agent
🌱 VITA — AI Health Companion

VITA is an AI-powered wellness assistant that helps users log daily health habits, ask health questions, and receive personalized lifestyle insights.

Built with a Live Mode + Demo Mode to ensure a smooth demo even without backend deployment.

🚀 Features
🗨️ AI health & lifestyle chat assistant
📊 Daily health logging (sleep, mood, water, exercise)
🧠 AI-generated wellness insights
🧪 Demo Mode for smooth usage without backend
🔄 Live backend support (FastAPI + Groq)
🏗️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Python, FastAPI
AI: Groq LLM API

▶️ Run Locally
git clone https://github.com/Nadeem-ux/Vita-ai-health-agent.git
cd Vita-ai-health-agent/backend
pip install -r requirements.txt
python server.py

Open index.html in browser.

🎥 Demo Flow
Open app
Toggle Demo Mode ON
Show logging → chat → insights
Toggle OFF to show live backend

🔒 Security
API keys stored in .env (not pushed to GitHub).
